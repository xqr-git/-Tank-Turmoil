# Tank-Turmoil
小型坦克对战游戏，支持单人模式，双人同键盘操作模式和局域网联机模式（有两人和三人），更详细说明见README
使用说明：
1.打开方式：用电脑下载文件，下载后双击文件“游戏启动.bat”，会有窗口打开，此时服务器已开启，在浏览器上输入网址即可进行游戏（网址为你电脑的IP地址，在窗口中可复制，网址在窗口中会被标为蓝色）；若要关闭服务器，关闭该窗口即可。

2.模式：有单人模式，双人模式和局域网联机模式。双人模式下双人在同一电脑上操作对战；局域网联机下，支持双人和三人对战。

3.设备使用：推荐电脑（Windows），不推荐手机。手机也可参与局域网连接，但无法进行本地模式，且不易操作（易受网页遮挡）。

4.操作键位：电脑端，w前进，s后退，a逆时针旋转，d顺时间旋转，j攻击键，k隐身；手机端，摇杆操作。

5.载体：游戏在网页上进行，只需要开启服务器的电脑下载压缩包，；如需局域网联机其它玩家浏览器搜索该电脑ip地址就行（不过需要连接同一WiFi或流量）。
