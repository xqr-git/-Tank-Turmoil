坦克动荡 · 局域网对战  使用说明
============================================================

【怎么开服】
  双击「游戏启动.bat」

  会弹出一个黑色窗口，上面写着：

      服务器开启中...
      http://192.168.1.5:8080      ← 这个就是进入游戏的网址

  窗口别关。一关，服务器就停了，其他人也就掉线了。

  谁点开这个文件，谁的电脑就是主机（服务器就跑在这台电脑上）。
  网址里的 IP 是这台电脑的局域网地址，换网络之后会变，以窗口里显示的为准。


【怎么玩】
  一个人玩：点首页的「单人模式」，先选电脑难度，再进战斗。
            一共四档：简单 / 中等 / 极难 / 莱卡（选过的档位会记住，下次自动带出）。
            · 简单：瞄得慢、常打偏（一半的炮是故意打歪的）、不会算反弹，先拿它练手；
            · 中等：会算一层反弹、会侧身躲弹，默认档；
            · 极难：反应更快、几乎不打偏，两层反弹也敢打，抢道具积极；
            · 莱卡：照《坦克动荡》官方那只 AI「莱卡」（Laika）的做法调的——
                    前方 230° 打 23 条射线找炮位、预判 2 次反弹、瞄准后几乎不等待
                    就开火、开火间隔压到最短、从不故意打偏，贴得也最近。
            电脑会自己找路、绕墙、躲子弹，也会跟你抢激光道具。
            电脑的脑子（电脑版、手机版完全同一套，没有任何差别）：
            · 开局就生成一条离你最近、能绕过障碍的路线，之后每 0.05 秒重算一次，
              新路线直接顶掉旧的，你一动它立刻改道；路线会走斜线，斜着穿过空地
              抄近道，不是只会横平竖直地拐直角；
            · 每帧预测未来 2 秒内有没有子弹会打中自己：
              没有 = 未受威胁状态，沿最短路线主动逼近、进攻、捡道具；
              有   = 躲避状态，优先闪身，闪的同时照样算「这一炮能不能命中你」，
                    算得出来就开火还击；
            · 自己弹夹打空（同时在场 4 颗子弹还没消失）时也算躲避状态，
              会倒着退开、车头仍对着你，等子弹腾出位置再打；
            · 后退不是直着蹭：会「一边倒车一边打方向」，车尾带着车身拐弯，
              贴太近、要绕开、要闪子弹都用这一招，比掉头再跑快得多。
            难度随时可以换：对局中按 P 暂停 → 主界面 → 再进单人模式重选。

  两个人同一台设备：点「双人游戏」。
            电脑上：一台键盘左右分区，红方 WASD、蓝方方向键。
            手机上：中间一张战场地图，屏幕上下两端各一条操作键——
            下侧是「红方操控键」（左下摇杆 + 右下开火），
            上侧是「蓝方操控键」（右上摇杆 + 左上开火）。
            摇杆推哪个方向，自己那辆车就往哪个方向开，两边规则完全一样。
            「蓝方操控键」那行字是上下颠倒的，因为上侧玩家是倒着看手机的。
            屏幕左侧空白有两排比分（红方数红字、蓝方数蓝字）：
            下面那排正的给红方看，上面那排倒过来给蓝方看。
            开火键旁边还有一块「血量 + 弹夹」小面板：红方那块在开火键左边，
            蓝方那块在开火键右边且整块上下倒转（他倒着看才是正的）；
            三颗心是血量，四颗小弹头是还能再打几发。
            上方那位玩家的开火键本身也是倒转的，他倒着看才是正的。
            屏幕右侧有个竖排的「主界面」小按钮，可以随时退出。
            手机建议用平板，屏幕大一点两人都看得清（那句提示可以点掉）。

  和朋友玩（局域网）：
  1. 所有玩家连同一个 Wi-Fi（同一个路由器，或同一个手机热点）
  2. 每个人用浏览器打开窗口里那个网址（电脑、手机、平板都行）
  3. 第一个人点「创建房间」，选 2 人对战 或 3 人对战，会得到一个 4 位房间码
  4. 其他人点「局域网联机」→ 输入房间码 → 加入房间
  5. 满了（或人齐了）房主点开始，开打

  主机自己也要玩的话，同样用浏览器打开那个网址。


【操作】
  ← ↑ ↓ →  或  W A S D      移动
  空格  或  J               开火
  K                         隐身（只有局域网联机有；单人 / 双人游戏没有）
  M                         静音
  Esc                       返回 / 退出房间（联机时对局内不设暂停）
  手机：用屏幕上的摇杆和按钮（左侧摇杆推向哪边就往哪开，右侧开火）
        双人游戏的手机上，上下两端各一套摇杆和开火键，一人一套，
        摇杆方向和自己那辆车的行进方向一致（两边都是推哪走哪）
  开始 / 继续：点一下屏幕就行（电脑上按空格也一样）

  单人模式的规则和双人游戏一样，区别只有一点：
    · 场上每 15 秒只刷一个「激光」道具（速度快、一发 2 滴血、用完即失）

  单人模式和双人游戏都没有隐身技能，双方始终看得见对方；
  隐身只在局域网联机里有（按 K）。


【连不上怎么办】
  · 先确认所有人连的是同一个 Wi-Fi（手机开了流量就会跑到外网，连不上）
  · 确认网址里的 IP 和窗口里显示的一致（换网后会变）
  · 第一次运行时 Windows 通常会弹出「防火墙」提示，一定点「允许访问」。
    如果当时点了取消，可以这样补救：
      控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙
      → 找到 Windows PowerShell，把「专用网络」勾上 → 确定
  · 实在不行，临时关掉防火墙试一下，能连上就说明是防火墙的问题
  · 端口默认用 8080，如果被别的程序占了，会自动换成 8081、8082……以窗口为准


【可能遇到的问题】
  · 窗口一闪就没了：说明启动出错，双击后如果看到英文报错，截图留着就能定位问题
  · 提示「禁止运行脚本」：正常双击「游戏启动.bat」不会出现；
    如果出现，说明组策略限制太严，需要联系管理员
  · 需要 Windows 10 及以上（用的是系统自带的 PowerShell，不需要装任何东西）


【文件说明】
  游戏启动.bat      ← 双击这个来开服
  使用说明.txt      ← 就是这个文件
  server.ps1        ← 服务器程序（由 bat 调用，不用管）
  index.html        ← 游戏页面
  game.js           ← 游戏主逻辑
  lobby.js          ← 大厅界面
  net.js            ← 联机通讯
  server.js         ← 备用服务器（需要电脑装了 Node.js，一般人用不到）

  除了「游戏启动.bat」，其它文件请不要改名或删除，
  否则游戏会打不开。
